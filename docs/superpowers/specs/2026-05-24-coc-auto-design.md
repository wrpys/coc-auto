# 部落冲突自动工具 (coc-auto) 设计文档

## 项目概述

**项目名称：** coc-auto
**目标平台：** 安卓11及以上（红米Note8 Pro，分辨率1080x2340，dpi:440）
**技术框架：** Auto.js（手机端运行）
**参考工具：** 爱玩coc免费辅助

### 核心功能
- 自动登录/多账号切换（通过QQ认证）
- 自动抢资源（金币、圣水、黑暗圣水）
- 自动升级（自定义优先级）
- 自动捐赠援军

## 项目架构

### 目录结构

```
coc-auto/
├── main.js                 # 入口文件，启动UI界面
├── ui/
│   ├── main_ui.js          # 主设置界面
│   ├── account_ui.js       # 账号管理界面
│   ├── upgrade_ui.js       # 升级优先级配置界面
│   └── settings_ui.js      # 运行设置界面
├── modules/
│   ├── login.js            # 自动登录模块（QQ认证集成）
│   ├── raid.js             # 自动抢资源模块
│   ├── upgrade.js          # 自动升级模块
│   ├── donate.js           # 自动捐赠模块
│   └── common.js           # 公共函数（点击、等待、截图等）
├── config/
│   ├── accounts.json       # 账号列表配置
│   ├── upgrade_priority.json  # 升级优先级配置
│   └── settings.json       # 运行设置（时间段、时长等）
├── logs/                   # 运行日志目录
├── assets/
│   └── images/             # 游戏界面截图素材（调试用）
└── project.json            # Auto.js项目配置文件
```

### 模块职责

| 模块 | 职责 |
|------|------|
| `login.js` | 启动coc、等待加载、通过QQ认证切换账号 |
| `raid.js` | 搜索敌人、判断资源量、部署兵力、收集战利品 |
| `upgrade.js` | 检查可升级建筑、按优先级执行升级 |
| `donate.js` | 监听捐赠请求、自动捐赠指定兵种 |
| `common.js` | 封装通用操作（点击坐标、滑动、等待元素、随机延迟） |

- 账号列表（可添加/删除/编辑）
- 每个账号配置：账号名称、QQ号、运行时长（分钟）、优先级顺序

- 建筑类型列表，可拖拽调整优先级：

### 设置界面（settings_ui.js）

- 运行时间段：开始时间、结束时间
- 搜索资源阈值：金币最低值、圣水最低值、黑暗圣水最低值
- 攻击策略：兵种选择、部署方式
- 捐赠配置：默认捐赠兵种、捐赠上限

## 核心模块逻辑

### 自动登录模块（login.js）

**流程：**
1. 检测coc是否在运行，若已运行则先关闭
2. 启动coc，等待加载完成
3. 进入游戏设置/账号管理界面
4. 点击"QQ认证"选项
5. 系统弹出QQ授权界面
6. 切换QQ账号：
   - 点击"切换账号"
   - 选择目标QQ账号
   - 确认授权登录
7. 等待游戏重新加载完成
8. 完成登录，返回成功状态

**关键点：**
- 需要预设"QQ认证"按钮和"切换账号"界面的坐标位置
- QQ授权弹窗可能需要滑动查找目标账号
- 登录成功后记录当前账号状态

### 自动抢资源模块（raid.js）

**流程：**
1. 确认在主界面
2. 点击"攻击"按钮进入搜索界面
3. 点击"搜索对手"
4. 等待加载完成，读取资源数量（金币、圣水、黑暗圣水）
5. 判断是否满足阈值条件：
   - 满足 → 执行攻击
   - 不满足 → 点击"下一个"返回步骤4
6. 攻击执行：
   - 按配置的攻击策略部署兵力
   - 等待战斗结束
   - 收集战利品返回主界面
7. 循环执行

**攻击策略（初始版本）：**
- 策略名称：`standard`（标准策略）
- 兵种：胡子（野蛮人）+ 弓箭手 + 哥布林
- 部署：先放胡子吸引火力，再放弓箭手输出，最后哥布林抢资源
- 后续可扩展：`barch`（胡子+弓箭手）、`goblin`（纯哥布林快抢）等策略

### 自动升级模块（upgrade.js）

**流程：**
1. 返回主界面
2. 遍历所有建筑位置（预设坐标列表）
3. 点击建筑 → 检测是否可升级（资源足够且未正在升级）
4. 若可升级，检查建筑类型是否在优先级列表中启用
5. 按优先级顺序升级：
   - 从最高优先级建筑开始
   - 资源足够就升级，资源不足则跳过
6. 遍历完成后，检查工人是否全部在用
7. 返回升级结果

**建筑位置：**
- 需要预设主界面所有建筑的坐标位置
- 通过缩放、滑动遍历所有建筑

### 自动捐赠模块（donate.js）

**流程：**
1. 检测部落聊天界面的捐赠请求气泡
2. 点击捐赠请求进入捐赠界面
3. 检测请求的兵种类型
4. 判断是否符合捐赠配置：
   - 符合 → 选择配置的捐赠兵种进行捐赠
   - 不符合（兵种未解锁/容量不足） → 跳过
5. 点击捐赠按钮
6. 等待捐赠完成，关闭捐赠界面
7. 返回主界面或继续检测下一个请求

**捐赠配置：**
- 默认捐赠兵种：胡子 / 弓箭手 / 哥布林 / 巨人 / 其他
- 每种兵种捐赠数量上限
- 是否只捐赠指定兵种

**触发机制：**
- 定时轮询：每隔N秒检查一次捐赠请求

## 配置文件结构

### accounts.json（账号配置）

```json
{
  "accounts": [
    {
      "name": "账号1",
      "qq": "123456789",
      "priority": 1,
      "run_duration": 30
    }
  ],
  "auto_switch": true,
  "switch_interval": 30
}
```

| 字段 | 说明 |
|------|------|
| name | 账号名称（显示用） |
| qq | QQ号（用于切换识别） |
| priority | 优先级（1最高） |
| run_duration | 单次运行时长（分钟） |
| auto_switch | 是否自动切换账号 |
| switch_interval | 切换间隔时间（分钟） |

### upgrade_priority.json（升级优先级）

```json
{
  "priority": [
    { "type": "townhall", "name": "大本营", "enabled": true },
    { "type": "goldmine", "name": "金矿", "enabled": true },
    { "type": "elixircollector", "name": "圣水收集器", "enabled": true },
    { "type": "darkdrill", "name": "黑暗圣水钻井", "enabled": true },
    { "type": "storage", "name": "储存器", "enabled": true },
    { "type": "wall", "name": "城墙", "enabled": true },
    { "type": "defense", "name": "防御建筑", "enabled": true },
    { "type": "other", "name": "其他", "enabled": true }
  ]
}
```

### settings.json（运行设置）

```json
{
  "schedule": {
    "start_time": "08:00",
    "end_time": "23:00"
  },
  "raid": {
    "gold_min": 100000,
    "elixir_min": 100000,
    "dark_min": 500,
    "attack_strategy": "standard"
  },
  "donate": {
    "enabled": true,
    "troops": ["barbarian", "archer"],
    "max_count": 5,
    "check_interval": 10
  },
  "delay": {
    "click_min": 500,
    "click_max": 1500,
    "action_min": 1000,
    "action_max": 3000
  }
}
```

| 配置项 | 说明 |
|--------|------|
| schedule | 运行时间段 |
| gold_min/elixir_min/dark_min | 搜索资源最低阈值 |
| attack_strategy | 攻击策略名称 |
| troops | 默认捐赠兵种 |
| max_count | 每次捐赠上限 |
| check_interval | 捐赠检查间隔（秒） |
| delay | 随机延迟范围（毫秒），模拟人工操作 |

## 错误处理与异常情况

### 常见异常处理

| 异常类型 | 检测条件 | 处理方式 |
|----------|----------|----------|
| 网络异常 | 加载超时（>30秒） | 重试3次，失败后记录日志并切换账号 |
| 游戏崩溃 | coc进程意外退出 | 等待5秒后重启coc并恢复运行状态 |
| 资源不足 | 升级所需资源低于当前持有 | 跳过升级，继续抢资源积累 |
| 工人占用 | 所有工人正在工作 | 暂停升级模块，专注抢资源 |
| 捐赠失败 | 兵营未生产完成 | 等待兵营生产完成后再捐赠 |
| 账号登录失败 | QQ授权失败或账号被封 | 记录失败状态，切换下一个账号 |

### 日志记录

- 日志文件：`logs/YYYY-MM-DD.log`
- 记录内容：时间戳、账号、操作类型、结果、错误信息
- UI界面提供查看最近日志入口
